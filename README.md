## 功能

- 首页 / 搜索 / 分类 / 榜单，真实数据
- 加密流解密播放：清晰度切换、倍速、选集、自动连播、进度续播
- 追剧 / 收藏 / 历史本地保存
- 深浅双主题
- Android 手机竖屏沉浸式体验；Windows 桌面版支持键鼠操作与窗口全屏

## 系统要求

- Android 7.0+
- Windows 10 / 11（x64）
